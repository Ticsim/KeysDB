If you update keys.txt
Git will mark it as modified.
You can then:
git status to see the change
git add keys.txt
git commit -m "Update keys.txt"
git push
Important note
If keys.txt contains secrets, pushing updates will keep them in the repo history.
In that case, it’s better to:
remove it from git
add it to .gitignore
use a secure secret management method instead
